# CNC Machine RFQ Checklist Lite

Use this checklist before requesting a CNC machine quotation. It helps suppliers understand the application and reduces avoidable clarification rounds.

## Workpiece and process

- [ ] Workpiece name and application
- [ ] Material grade and condition
- [ ] Maximum dimensions and weight with units
- [ ] Required operations such as turning milling drilling or grinding
- [ ] Critical tolerances and surface finish
- [ ] Monthly or annual production volume
- [ ] Latest drawing revision attached

## Machine requirements

- [ ] Preferred machine type or permission for the supplier to recommend one
- [ ] CNC control preference if applicable
- [ ] Automation requirement
- [ ] Electrical standard including voltage frequency and phase
- [ ] Required accessories
- [ ] Inspection or acceptance requirement

## Commercial requirements

- [ ] Destination country and city
- [ ] Requested Incoterm and named place
- [ ] Quotation currency
- [ ] Target delivery window clearly marked as a target not a supplier commitment
- [ ] Standard optional and custom items requested separately
- [ ] Unknown information marked TBD instead of guessed

## Quote review

- [ ] Technical deviations are listed
- [ ] Excluded costs are listed instead of treated as zero
- [ ] Lead time start event is defined
- [ ] Quotation validity is clear
- [ ] Warranty and support scope is written
- [ ] Inspection and acceptance method is written
- [ ] Final scope matches the latest drawing revision

This checklist is a general sourcing aid. Verify all project specific technical commercial legal tax customs and contract information before making a decision.
